# 首次 APK 真机验收清单

> 适用版本：知行 Android App 0.1.2 Debug 预览版（安装前以 APK 内实际 versionName / versionCode 为准）  
> 当前阶段：原生主壳与导航 / 我的页面已实现；计算器数学内核正在迁移，尚不是功能完整的计算器。

## 安装前

- [ ] 从 GitHub Actions 下载 `zhixingapp-debug` Artifact ZIP。
- [ ] 解压 ZIP，确认其中存在 `app-debug.apk`。
- [ ] 确认下载文件来自最新的成功构建，而不是旧运行的 Artifact。
- [ ] 首次安装时允许文件管理器/浏览器安装未知应用（仅对可信 APK 操作）。

## 启动与首页

- [ ] 安装成功，桌面显示“知行”名称。
- [ ] 桌面图标显示用户提供的蓝紫渐变知行标识。
- [ ] 点击图标可以正常启动，不闪退、不白屏。
- [ ] 首页顶部品牌标识完整，没有被状态栏遮挡。
- [ ] 页面没有横向滚动条或内容溢出。

## 导航与「我的」页面

- [ ] 一级导航顺序为「计算 / 知行 AI / 工具 / 我的」。
- [ ] 四枚圆润、带填色的图标视觉重量一致，默认态与选中态都清晰。
- [ ] 底部导航为浮动液态玻璃 Dock；背景适度模糊，页面背景能自然透出。
- [ ] Dock 不遮挡最后一项内容，手势导航区域可正常操作。
- [ ] 连续切换一级入口时，选中胶囊连续滑动，不闪烁、不跳位。
- [ ] 「我的」页面显示真实的最近使用空状态、历史记录入口、材质设置入口和应用版本信息。
- [ ] 从「我的」进入历史 / 材质二级页面时有淡入、轻微位移和缩放动画，不是瞬间出现。
- [ ] 从二级页面返回后，「我的」的选中状态、滚动位置和对应设置状态得到保留。
- [ ] 连续进入 / 返回二级页面不会闪退或丢失底部导航。

注意：计算、知行 AI 和工具的业务功能仍在迁移；历史页面目前没有本地计算历史数据，不应出现虚构记录。

## 系统栏与屏幕适配

- [ ] 浅色背景上的状态栏图标清晰可见。
- [ ] 底部手势区域或三键导航区域没有明显遮挡。
- [ ] 竖屏布局完整。
- [ ] 如设备允许，旋转横屏后不发生崩溃或严重错位。
- [ ] 系统字体放大后主要文字仍可阅读。
