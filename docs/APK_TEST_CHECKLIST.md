# 首次 APK 真机验收清单

> 适用版本：知行 Android App 0.1.2 Debug 预览版（安装前以 APK 内实际 versionName / versionCode 为准）  
> 当前阶段：原生主壳与导航 / 我的页面已实现；计算器数学内核正在迁移，尚不是功能完整的计算器。

## 安装前

- [ ] 从 GitHub Actions 下载 `zhixingapp-debug` Artifact ZIP。
- [ ] 解压 ZIP，确认其中存在 `app-debug.apk`。
- [ ] 确认下载文件来自最新的成功构建，而不是旧运行的 Artifact。
- [ ] 首次安装时允许文件管理器/浏览器安装未知应用（仅对可信 APK 操作）。

## 启动与首页

- [ ] 安装成功，桌面显示“知行”名称。
- [ ] 桌面图标显示用户提供的蓝紫渐变知行标识。
- [ ] 点击图标可以正常启动，不闪退、不白屏。
- [ ] 首页顶部品牌标识完整，没有被状态栏遮挡。
- [ ] 页面没有横向滚动条或内容溢出。

## 导航与「我的」页面

- [ ] 一级导航顺序为「计算 / 知行 AI / 工具 / 我的」。
- [ ] 四枚圆润、带填色的图标视觉重量一致，默认态与选中态都清晰。
- [ ] 底部导航为浮动液态玻璃 Dock；背景适度模糊，页面背景能自然透出。
- [ ] Dock 不遮挡最后一项内容，手势导航区域可正常操作。
- [ ] 连续切换一级入口时，选中胶囊连续滑动，不闪烁、不跳位。
- [ ] 「我的」页面显示真实的最近使用空状态、历史记录入口、材质设置入口和应用版本信息。
- [ ] 从「我的」进入历史 / 材质二级页面时有淡入、轻微位移和缩放动画，不是瞬间出现。
- [ ] 从二级页面返回后，「我的」的选中状态、滚动位置和对应设置状态得到保留。
- [ ] 连续进入 / 返回二级页面不会闪退或丢失底部导航。

注意：计算、知行 AI 和工具的业务功能仍在迁移；历史页面目前没有本地计算历史数据，不应出现虚构记录。

## C8.8.1–C8.8.2 单位换算页面真机验收（Build #428）

> 本节是待执行的设备检查清单。Build #428 只证明 JVM 单测、androidTest 源码编译和 Debug APK 组装成功；**不能勾选下列真机项来代替实际设备检查**。按用户要求，本轮不执行任何真机验收。

### 入口与导航

- [ ] 从底部「工具」进入工具目录，单位换算入口有完整标题和说明，不被浮动 Dock 遮挡。
- [ ] 点击单位换算后进入独立二级页面，具有页面过渡动画；不闪退、不白屏。
- [ ] 点击玻璃返回按钮 / Android 系统返回键均能返回工具目录；再次进入时状态符合产品预期。
- [ ] 单位换算页面背景、卡片和返回按钮使用知行浅色玻璃材质；公式和结果文字保持清晰，不出现大面积深色块。
- [ ] 长列表、类别栏和结果区域滚动顺畅，不与底部 Dock / 系统手势冲突。

### 九类目录与默认选择

逐类检查名称、单位标签、下拉列表顺序和默认源 / 目标单位：

| 类别 | 默认源 → 目标 |
|---|---|
| 长度 | m → ft |
| 面积 | m² → ft² |
| 体积 | l → ml |
| 质量 | kg → lb |
| 温度 | °C → °F |
| 速度 | km/h → m/s |
| 时间 | h → min |
| 数据存储 | MB → GB |
| 角度 | deg → rad |

- [ ] 九类均可选；窄屏时类别栏可横向滚动，不压缩成不可读的小按钮。
- [ ] 每类的源 / 目标单位下拉均展示该类别全部单位，标签没有截断到无法辨认。
- [ ] 类别切换会采用对应默认单位，不会沿用上一类别中同 ID 的单位（特别检查 speed/ms 与 time/ms）。

### 输入、换算和错误状态

- [ ] 初始输入为空时只显示输入提示，不显示 0 或旧结果。
- [ ] 输入整数、小数、负数后即时更新；快速修改、全选替换和连续删除均不丢字符。
- [ ] 空格 / 空输入、非法文本、粘贴非有限文本时，输入错误状态清楚，不将失败换算显示为 0。
- [ ] 长度：1 m → ft，结果约为 3.280839895。
- [ ] 温度：0 °C → 32 °F；32 °F → 0 °C；0 K → 约 −273.15 °C。
- [ ] 时间：1 h → 60 min；速度：1 km/h → 约 0.27777778 m/s。
- [ ] 低于绝对零度的温度显示明确错误，不给出貌似有效的数字。
- [ ] 极大值 / 极小值、结果溢出或无法表示的精度边界不会显示 NaN / Infinity；错误文案可理解。

### 单位选择、交换和同类单位一览

- [ ] 修改源单位后结果立即更新；修改目标单位后结果立即更新。
- [ ] 点击 ⇄ 后源 / 目标单位互换，输入值保持不变，结果按反向换算重新计算。
- [ ] 同类单位一览包含当前类别所有单位，数值与选定源输入对应。
- [ ] 当前目标单位高亮正确；切换目标单位后高亮随之移动。
- [ ] 同类列表中出现数值范围错误时有可理解提示，不出现崩溃或空白整页。

### 输入法、安全区与屏幕适配

- [ ] 点击输入框后弹出十进制输入键盘；小数点、负号、退格、全选 / 粘贴可用。
- [ ] IME 弹出时输入框和结果能通过滚动访问；底部内容不被键盘或系统导航区遮住。
- [ ] 隐藏键盘后页面位置稳定，不突然跳到顶部或丢失输入。
- [ ] iQOO Neo5 活力版竖屏下无横向溢出、按钮重叠或文字裁切。
- [ ] 360dp 左右窄屏、系统字体放大和旋转场景下布局仍可用。
- [ ] TalkBack / 无障碍焦点能区分类别、源单位、目标单位、交换和返回操作；焦点顺序合理。
