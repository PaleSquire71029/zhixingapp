# 首次 APK 真机验收清单

> 适用版本：知行 Android App 0.1.0 Debug 预览版  
> 当前阶段：原生 UI 骨架，不是完整计算器。

## 安装前

- [ ] 从 GitHub Actions 下载 `zhixingapp-debug` Artifact ZIP。
- [ ] 解压 ZIP，确认其中存在 `app-debug.apk`。
- [ ] 确认下载文件来自最新的成功构建，而不是旧运行的 Artifact。
- [ ] 首次安装时允许文件管理器/浏览器安装未知应用（仅对可信 APK 操作）。

## 启动与首页

- [ ] 安装成功，桌面显示“知行”名称。
- [ ] 桌面图标显示用户提供的蓝紫渐变知行标识。
- [ ] 点击图标可以正常启动，不闪退、不白屏。
- [ ] 首页顶部品牌标识完整，没有被状态栏遮挡。
- [ ] 页面没有横向滚动条或内容溢出。

## 导航

- [ ] “计算”入口可选中。
- [ ] “知行AI”入口可选中。
- [ ] “工具”入口可选中。
- [ ] “历史”入口可选中。
- [ ] 连续切换入口不会闪退或丢失底部导航。

注意：这些目前是占位入口；它们可切换不代表计算、聊天、工具或历史功能已经实现。

## 系统栏与屏幕适配

- [ ] 浅色背景上的状态栏图标清晰可见。
- [ ] 底部手势区域或三键导航区域没有明显遮挡。
- [ ] 竖屏布局完整。
- [ ] 如设备允许，旋转横屏后不发生崩溃或严重错位。
- [ ] 系统字体放大后主要文字仍可阅读。

## 反馈原则

优先提供截图和可复现步骤。遇到安装失败，保留 Android 提示原文；遇到闪退，说明是启动即闪退还是点击某个入口后闪退。不要把占位功能尚未实现当作 APK 构建故障。
